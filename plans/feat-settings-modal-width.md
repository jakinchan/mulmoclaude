# 設定モーダルの幅を広げる（#1898）

作成日: 2026-07-31

## 背景

スキル編集は以前は独立画面だったが、SettingsModal に統合された結果、入力欄が狭くなった。
広いモニターを使っていても幅を活用できず、手動編集がしづらいという beta-feedback（#1898）。

## 現状の実装

`src/components/SettingsModal.vue`

| クラス | 役割 | 実際の値 |
|---|---|---|
| `w-[64rem]` | skills / roles タブ（`isFullTab`）の幅 | 固定 1024px |
| `w-[52rem]` | その他（フォーム系）タブの幅 | 固定 832px |
| `max-w-[95vw]` | 小画面でのはみ出し防止 | ビューポート幅の 95% |

左ナビが `w-44`（176px）なので、スキル編集エリアの実効幅は約 850px。
`w-[64rem]` は固定値のため、1970px のモニターでも 1024px までしか広がらない。

## 方針

モーダル幅を固定 rem から vw ベースへ変更し、**全タブで同じ幅に統一**する
（タブ切り替え時に幅が変わる挙動もあわせて解消される）。

```
- :class="isFullTab ? 'w-[64rem] h-[85vh]' : 'w-[52rem]'"
+ class="... w-[min(88vw,90rem)] max-w-[95vw] ..."
+ :class="{ 'h-[85vh]': isFullTab }"
```

- `88vw`: 画面幅に追従。1440px 画面で 1267px（現状 1024px）
- `90rem`（1440px）: 超ワイドモニターでの間延び対策の上限キャップ
- `max-w-[95vw]`: 小画面ガードとしてそのまま維持
- 高さは現状維持（`isFullTab` のみ `h-[85vh]`。フォーム系はコンテンツ高 + `max-h-[85vh]`）

フォーム系タブは、広がったモーダル幅いっぱいに入力欄が伸びると読みにくいため、
コンテンツ側に `max-w-[52rem]`（= 従来のモーダル幅）を付けて制限する。
フッターのステータス行も左寄せなので、左寄せのまま余白が右に出る形で揃う。

## スコープ外

issue タイトルにある「resizable（ユーザーによるドラッグリサイズ）」は本 PR では実装しない。
まず幅を広げることで要望（「以前くらいの画面幅が欲しい」）を満たし、
必要ならドラッグリサイズ + localStorage 永続化を別 issue / PR で検討する。

## 手順

1. `src/components/SettingsModal.vue` のルート要素の幅クラスを差し替え
2. フォーム系タブのコンテンツに `max-w-[52rem]` を追加
3. `yarn format` / `yarn lint` / `yarn typecheck` / `yarn build` / `yarn test`
4. e2e（`e2e/tests/settings.spec.ts`）が幅に依存していないことを確認
   - backdrop クリックで閉じるテストが `position: { x: 5, y: 5 }` を使うが、
     モーダルは中央寄せかつ最大 95vw なので左上 5px は依然 backdrop
